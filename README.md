# Copiloto STUDY — Node.js + TypeScript

Desafio de projeto do bootcamp jornada para o futuro - Node.js da DIO: personalizar um copiloto de IA
através de um arquivo de instruções, definindo identidade, personalidade e
regras de comportamento.

## Sobre

O arquivo [`.github/copilot-instructions.md`](.github/copilot-instructions.md)
configura o copiloto para atuar como tutor técnico, focado em Node.js e
TypeScript, priorizando aprendizado real em vez de respostas rápidas.

## Personalidade

Persona estilo "Cortana": tom calmo, confiante, direto e didático.

## Stack de referência

Node.js, TypeScript, Express/Fastify, Jest/Vitest.
